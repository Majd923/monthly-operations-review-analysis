# Monthly Operations Review – Data Analyst Assessment

## Overview
This project analyzes the operational and financial performance of three store branches using sales, operating cost, and customer feedback data.

## Objectives
- Calculate Net Profit and Profit Margin %
- Compare branch profitability visually
- Perform customer sentiment analysis
- Recommend performance improvements based on financial and qualitative insights
- Evaluate the impact of reducing operational costs for Branch C

## Tools Used
- Microsoft Excel
- Microsoft Word
- GitHub

## Key Findings
- Branch B achieved the highest profitability and strongest customer satisfaction.
- Branch A performed moderately well but experienced operational delays.
- Branch C generated the highest sales revenue but suffered from high operational costs and poor delivery feedback.
